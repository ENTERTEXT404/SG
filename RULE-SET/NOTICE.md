# DIRECT.list 网段来源

中国 IPv4 和 IPv6 网段改编自 [Sukka's Ruleset](https://github.com/SukkaW/Surge) 的 [IPv4](https://ruleset.skk.moe/List/ip/china_ip.conf) 和 [IPv6](https://ruleset.skk.moe/List/ip/china_ip_ipv6.conf) 名单。两份下载文件均标注 [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)。

上游列出的数据来源为 [Misaka Network 的 chnroutes2](https://github.com/misakaio/chnroutes2) 和 [gaoyifan 的 china-operator-ip](https://github.com/gaoyifan/china-operator-ip)。本项目对网段做了筛选、去重、合并和排序。
